# 半自动配载系统 (Semi-Auto Container Loading)

国际物流集装箱配载引擎 — 输入价格表、船期表、订单汇总表，自动生成排柜方案。

## 快速开始

```bash
cd D:\价格表
npm install
node engine/cli.js
```

## 数据要求

- **美国华南汇总.xlsx** — 订单汇总 + 船期（华南/华东SO）+ 带电订单
- **价格表** — 6 份 Excel，按区域/供应商区分

## 输出

`排柜结果/排柜方案_YYYYMMDD.xlsx` — 包含每个集装箱的订单明细、费用汇总、未装柜报告、审核检查单。

## 配套审核界面

浏览器打开 `排柜审核.html`，拖拽生成的排柜方案 Excel 即可可视化审核。
